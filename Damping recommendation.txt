1. Is the Moose Test suitable for fitting roll damping?

Yes, but with caution.

The Moose Test / ISO double-lane-change is suitable because it has strong left-right transient lateral acceleration. That excites:

roll angle
roll rate
yaw-roll coupling
lateral load-transfer transient
roll overshoot after steering reversal
roll settling after lane recovery

ISO 3888-2 is specifically a severe closed-loop lane-change / obstacle-avoidance track intended to evaluate a part of vehicle dynamics and road-holding ability. The current ISO page shows ISO 3888-2:2025 as the published version, with ISO 3888-2:2011 withdrawn.

However, for parameter identification, I would say:

Moose Test = good validation and useful fitting maneuver
but not the cleanest first identification maneuver

The cleaner tests are open-loop steering tests, because they remove the driver/path-following ambiguity. ISO 7401:2011 is directly relevant because it specifies open-loop methods for lateral transient response of road vehicles.

So my recommendation is:

Best identification order:
1. Step steer / sine steer / sine-with-dwell / slalom at fixed speed
2. Moose Test / double lane change for validation and final retuning
